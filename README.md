**Indigo CG** is a high-performance Android application designed to simplify aircraft load management and weight and balance calculations. Built with a focus on accuracy and situational awareness, the app features a unique 3D interactive dashboard that allows users to visualize and manipulate the aircraft's center of gravity with ease.

## 🚀 Key Features

* **3D Interactive Visualization:** Features a movable 3D airplane model that responds to touch, allowing for intuitive visualization of load distribution.
* **Precise CG Calculations:** Automates the calculation of the Center of Gravity (CG), total moments, and weights to ensure flight safety.
* **Real-time Dashboard:** A comprehensive professional-grade dashboard that displays all critical aviation metrics in a single view.
